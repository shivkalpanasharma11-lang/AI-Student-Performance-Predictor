# AI-Powered Student Performance Predictor

**ML-Based Academic Performance Analysis System**

This Python 3.14-friendly project uses a custom K-Nearest Neighbors (KNN) algorithm, so it does not require scikit-learn or SciPy.

## Run
```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```
